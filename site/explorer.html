Pitcher Explorer

Pick any Royals pitcher with 300+ pitches in 2026. Movement, release, location and count usage all come from his actual pitches. Movement is from the pitcher's arm side (+ = arm side) so righties and lefties read the same way. Charts use a random sample of up to 450 pitches; the table uses every pitch.

Printable pitcher card ↗

Velo/Max in mph · Spin in rpm · IVB/HB in inches · Ext = extension (ft) · VAA = vertical approach angle (°) · Rel Δ = release-point offset from his primary fastball (inches, height / side) · Whiff = whiffs per swing, with its 95% Wilson interval · Chase = swing rate out of zone · CSW = called + swinging strikes per pitch · RV/100 = run value per 100 pitches, pitcher's view (+ is good) · Stuff+ = this project's shape-only model (100 = MLB average, see Research).

Movement profile: dots are pitches, rings are pitch-type averages labeled with average velocity. The gold callout marks his best pitch by Stuff+.

Batter side

Catcher's view. Height is scaled to each hitter's strike zone (0 = bottom, 1 = top). Whiff map shows only cells with 4+ swings; the callout appears only when both the zone and the area below it have 50+ swings.

Pitch mix in every count. Pitchers with stable usage are harder to sit on; big swings from count to count show what hitters can look for.
