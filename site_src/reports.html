Daily pitching report

For each pitcher who threw: velocity, ride, run, spin and release vs his own season baseline, with automatic flags (velocity down 1.5+ mph, shape change of 2+ inches, release drift of 4+ inches). It also covers workload (rest days, pitches over the last 7 days) and an attack / avoid / put-away sheet for each opposing hitter, using shrunk splits by pitch group.

Pitcher card / game plan

One page per pitcher, built for a coach: three takeaways in big type (attack, avoid, watch), then three small charts (movement, location by count, put-away usage), each with one gold sentence to remember, and compact arsenal and batter-hand tables last. Every sentence is computed from the data, and rates are quoted only with 50+ swings, so it updates daily without anyone rewriting it.
