How it's built

A small, reproducible pipeline designed the way I'd want a club's daily pipeline to work: raw data in, versioned SQL transforms, R for modeling and reports, and static outputs anyone can open. Python is only used for the download and page assembly.

Data

  • Source: Baseball Savant Statcast search CSV, regular season 2026, all 30 clubs, pulled one day per request.
  • pitches in games, to , after dropping pitchouts, intentional balls and unclassified pitches.
  • Royals pitchers: pitches by pitchers. The explorer shows the 20 with 300+.
  • Player names come from the MLB Stats API. The raw CSVs (~470 MB) stay outside the site, which ships only small pre-aggregated JSON.

Key definitions

  • IVB / HB: Statcast pfx_z, pfx_x in inches. HB is mirrored for lefties (+ = arm side).
  • VAA: angle at y = 17/12 ft from the 9-parameter fit. Location-adjusted VAA = residual of VAA regressed on zone-normalized height.
  • Tunnel gap: distance between consecutive pitches 23.8 ft in front of the plate, back-solved from plate location.
  • xRV: pitch run value (delta_run_exp, pitcher view). Balls in play are replaced by the league-average value for that exit velocity, launch angle and count.
  • Shrinkage: (sum + k·league) / (n + k), with k = 250 pitches for run values and k = 60 for hitter splits.

Reproduce it

git clone https://github.com/devin182/royals-pitching-rd.git && cd royals-pitching-rd
make all        # fetch → sql → model → analysis → reports → pdf → pages   (about 15 min, mostly download)
make report     # rebuild only the daily report + pitcher cards from the existing database
python3 -m http.server -d site 8000
